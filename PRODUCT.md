# Product

## Register

product

## Users

DeFi users who need to deposit into, withdraw from, migrate between, and manage
positions in Yearn vaults. They may use an EOA or Safe, interact on multiple
chains, and arrive with different levels of protocol familiarity.

## Product Purpose

The vault widget provides one trustworthy surface for executing and monitoring
Yearn vault actions. Success means users can understand the asset flow, review
the expected result and risk controls, complete every required transaction
step, and recover from errors without leaving the vault page.

## Brand Personality

Direct, precise, and reassuring. The interface should feel unmistakably Yearn
while letting each host application express its own surrounding visual system.

## Anti-references

Avoid promotional fintech treatments, decorative transaction choreography,
ambiguous wallet prompts, hidden approval or routing steps, and styling that
competes with the action being reviewed.

## Design Principles

- Make the asset path and next required action explicit.
- Keep transaction state visible from wallet confirmation through settlement.
- Use familiar controls and consistent language across every vault variant.
- Treat routing, slippage, approvals, and wallet type as user-facing safety
  concerns rather than implementation details.
- Provide strong defaults while allowing host applications to theme and compose
  the surface without forking its behavior.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve semantic controls, full keyboard operation,
visible focus states, status announcements, sufficient contrast, large touch
targets, reduced-motion preferences, and meaning that does not rely on color
alone.
